## 面试时可以解释的技术点

1. **BGR 与 HSV**：OpenCV 默认彩色顺序是 BGR；HSV 将色调与饱和度、亮度分离，蓝色示例使用 H=90–130、S/V 下界为 50 的阈值。阈值依赖场景和光照。
2. **OpenCV 加法与 NumPy 加法**：两个 uint8 值相加时，`cv.add` 饱和到 255；NumPy 数组加法在 uint8 下模 256 回绕，例如 250+10 分别得到 255 和 4。
3. **形态学**：腐蚀收缩前景，膨胀扩张前景；开运算先腐蚀后膨胀，常用于抑制小前景噪点；闭运算的顺序相反，可填补小间隙。效果取决于前景定义和结构元素。
4. **轮廓与外接矩形**：阈值化后查找轮廓，按面积筛选；`boundingRect` 为轴对齐矩形，`minAreaRect` 可以旋转。示例使用 `RETR_TREE`，因此轮廓数量包含层级中的内部边界，不能直接当作目标数。
5. **模板匹配**：`TM_CCOEFF_NORMED` 通过局部相关性寻找最佳位置；本例模板从输入中裁出，匹配接近 1.0 是流程验证，不代表在其他场景的识别准确率。
6. **霍夫变换**：在参数空间投票寻找线段或圆；结果依赖边缘质量和阈值。当前脚本输出候选几何结构，未做目标分类或跟踪。
7. **运行可靠性**：相对脚本解析素材路径；用编码/解码加 NumPy 文件 I/O 处理中文图片路径；检查读写器状态并在 `finally` 中释放视频资源；无检测结果时仍输出可查看图像。

目前未实现相机标定、实机视觉闭环、深度学习训练、目标跟踪和实时性能评测。可继续增加可配置 ROI、独立模板输入、参数配置文件、不同光照条件下的分割对比，以及带标注数据的检测评估；这些属于后续方向，不写作已完成成果。
