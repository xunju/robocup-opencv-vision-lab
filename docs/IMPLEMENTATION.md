# 从第二次任务到可复现项目

## 原作业与仓库的对应关系

| 原脚本 | 保留的实验内容 | 整理与改进 |
| --- | --- | --- |
| `task1_gui_draw.py` | 读图、灰度、绘制图形、手工框与文字 | 标注明确写为手工绘图；默认不弹窗、不等待按键 |
| `task2_video.py` | 视频元数据、帧编号、编码与帧导出 | 可选按间隔导出；增加最大帧数、读写器检查和资源释放 |
| `task3_core.py` | ROI、通道、边界、加法、融合、掩膜、灰度耗时 | 蓝通道反相使用 NumPy 切片；保存灰度对照图和运行指标 |
| `task4_basic.py` | HSV、几何变换、平滑、形态学 | 统一 I/O 与命名；显式保存 HSV 掩膜 |
| `task5_advanced.py` | 梯度、Canny、金字塔、轮廓、均衡化、模板和霍夫 | 检查空轮廓/空线段；即使未检出圆也保存结果；使用 ASCII 标签避免 OpenCV 默认字体无法显示中文 |

原始作业仍保留在工作区的原目录；此仓库仅包含整理后的独立副本。课程文档、Word 临时文件、macOS 元数据和历史输出未导入仓库。输入素材沿用原作业文件。

## 运行约定

- 原算法按 5 个任务模块组织，保留独立启动能力。
- `common.py` 集中处理参数、文件读写和可选预览。
- `run.py` 默认执行全部任务，`--task` 可选择单个模块，并保存环境版本与模块结果。
- 不指定 `--show` 时不调用 GUI 预览，适用于批处理和 CI。
- `output/` 为可再生成目录；文档只提交代表性预览与一次示例报告。
- 输入视频与目标视频禁止使用同一路径，避免覆盖源文件。

## 结果阅读

- `smoothing.png`：原图、均值滤波、高斯滤波、中值滤波、双边滤波。
- `morphology.png`：二值图、腐蚀、膨胀、开运算、闭运算。
- `gradients.png`：原灰度图、Sobel X、Sobel Y、Laplacian。
- `canny_*.png`：原灰度图、高斯滤波、对应双阈值的 Canny。
- `pyramid.png`：原图、两次下采样后一次上采样并调整回原尺寸的图像。
- `histogram_equalized.png`：均衡化前与均衡化后。
- `template_matching.png`：左侧显示模板位置示意，右侧为输入图中的匹配框。
- `contour_boxes.png`：绿色轴对齐矩形、红色最小面积旋转矩形。

报告中的灰度性能测量只针对 64 × 64 的单个图像片段，各实现还存在取整差异；固定阈值、形态学核和几何点均针对示例素材设置。

## 本地验证记录

- 环境：Windows、Python 3.12.7、OpenCV 4.11.0、NumPy 2.0.2。
- 命令：`python -m unittest discover -s tests -v`，6 项检查通过。
- 命令：`python run.py --extract-every 30`，全部 5 个模块运行结束。
- 图像：生成 37 张静态实验图，另外提取 17 张视频帧。
- 视频：830 × 986、30 FPS、写入 526 帧。
- 完整数值记录见 `sample_report.json`；远端 CI 状态以 GitHub Actions 实际运行结果为准。
